# 项目整体说明

## 1. 项目是什么

**云顶之弈对局决策助手**——一个本地运行的 Web 应用，帮助玩家在《云顶之弈》（Teamfight Tactics）中做出更好的对局决策。

当前适配赛季：**Set 18「苍林秘境」** ｜ 最新补丁：**18.3**

## 2. 要解决的问题

### 2.1 已有工具的缺口

市面上已有大量阵容推荐工具，但它们普遍存在两个缺口。

**缺口一：只给结论，不给依据**

它们列出"当前 T0 阵容"和第三方统计的使用率、平均名次。玩家知道"什么强"，但不知道**为什么强**，因此无法判断：

- 这个补丁对我手上正在玩的阵容意味着什么？
- 我来的牌和装备明显不适合这套，还能硬玩吗？
- 这套被削了之后，该转什么？

**缺口二：会静默失效**

云顶有一个特殊性质：**每约 4 个月更换赛季，全部英雄、羁绊、装备被清空重建**。

这意味着任何依赖静态数据的工具都会在换季时**静默失效**——它不会报错，仍然在输出阵容，只是输出的是上上个赛季的。用户往往要玩过几局之后才察觉。

### 2.2 本项目的回应

| 缺口 | 回应 |
|---|---|
| 只给结论 | **补丁驱动的推导**：改动 → 受影响英雄 → 所属阵容 → 强度增量。每条梯队结论都能展开看到依据的改动条目与官方来源 |
| 静默失效 | **版本指纹校验**：赛季不一致时直接阻断，补丁落后时显式警告，而非静默降级 |
| 大模型胡说 | **三道幻觉闸门**：白名单约束、结构化输出校验、确定性工具核验 |

## 3. 目标用户

| 用户 | 需求 |
|---|---|
| **上分玩家** | 想知道当前版本什么阵容强，以及为什么 |
| **阵容专精玩家** | 想知道自己擅长的阵容这个补丁被加强了还是削弱了 |
| **对局中玩家** | 想快速判断"这局该走哪个方向""这 50 块该 D 还是拉人口" |
| **回归玩家** | 隔了一个赛季回来，需要快速了解当前环境 |

## 4. 核心功能

### 4.1 阵容总览

按梯队展示当前版本阵容。每张卡片包含：

- 核心英雄（费用描边头像）
- 羁绊构成与激活档位
- 核心装备分配
- 运营节奏（何时升人口、何时 D 牌）
- **「为什么是 T0」可展开面板**——列出依据的补丁改动与官方来源外链

### 4.2 局面咨询

输入当前局面（阶段、等级、金币、血量、连胜连败、已有英雄、装备、海克斯、对手信息），提问或使用快捷指令：

| 指令 | 回答什么 |
|---|---|
| 推荐方向 | 当前最优方向与本回合操作 |
| 海克斯选择 | 三选一，先给结论再给理由 |
| D 牌决策 | 本回合 D 牌还是存钱 / 拉人口，给具体金币预算 |
| 站位建议 | 当前阵容的最优站位 |
| 对手针对 | 根据对手信息给针对思路 |
| 是否转型 | 要不要转，转就给目标和步骤 |

### 4.3 数据速查

英雄 / 羁绊 / 装备 / 海克斯的可搜索列表，含完整数值。

这一层看似附属，实际是**校验能力的可视化**——用户能自行查到真实数据，就不容易被模型带偏。

## 5. 关键设计选择

完整的推导过程见 [DESIGN.md](DESIGN.md)。以下是结论性的选择：

| 选择 | 理由 |
|---|---|
| **事实来自数据，判断来自模型** | 数值计算有唯一正确答案，不该交给概率模型 |
| **阵容由补丁推导，而非人工录入** | 保证"为什么强"这个信息不丢失，且换补丁成本低 |
| **不抓取第三方统计数据** | 第三方站点无公开 API，页面结构变动即失效，属于脆弱依赖 |
| **采用结构化输入表单 + 自然语言** | 纯自然语言容易漏项；纯表单不够灵活。两者并存 |
| **数据分三种存储** | 游戏数据用 JSON 包、知识层用 Markdown、动态数据用 SQLite，各取所长 |

## 6. 明确的非目标

以下内容**不在本项目范围内**，避免范围蔓延：

| 非目标 | 原因 |
|---|---|
| 自动抓取真实胜率 / 登场率统计 | 第三方站点无公开稳定 API |
| 对局内存读取、模拟器插件 | 存在账号封禁风险 |
| 截图视觉识别棋盘 | 需要训练数据集与独立模型服务，非核心价值 |
| 用户系统、账号体系 | 本地工具，无此需求 |
| 云端部署与多用户服务 | 定位是本地工具 |

## 7. 技术要求

| 项 | 要求 |
|---|---|
| 运行环境 | Node.js 22+ |
| 运行方式 | 本地启动，浏览器访问 |
| 网络 | 首次同步数据需要访问 Community Dragon；之后可离线使用阵容库与速查 |
