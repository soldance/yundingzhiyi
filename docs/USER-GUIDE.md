# 使用说明

> 面向使用者的功能说明。
>
> ⚠️ **项目尚未开始编码。** 本文档描述的是**设计中的使用方式**，用于确认需求边界；界面与功能将在 [路线图](ROADMAP.md) 的各阶段落地。

---

## 1. 这是什么

**云顶之弈对局决策助手**——一个在本地运行的网页工具，帮助你在《云顶之弈》中做出更好的决策。

它和常见的阵容推荐工具最大的不同是：

> **它不只告诉你"什么阵容强"，还告诉你"为什么强"，并给出依据的官方来源。**

当前适配赛季：**Set 18「苍林秘境」**

---

## 2. 它能做什么

### 2.1 阵容总览

查看当前版本的阵容梯队。每套阵容展示：

- **核心英雄**，按费用配色区分
- **羁绊构成**与已激活的档位
- **核心装备**分配给谁
- **运营节奏**：什么时候升人口、什么时候刷牌
- **「为什么是 T0」** —— 点开后可以看到这套阵容的依据，例如：

  > ▲ 本次补丁该阵容核心英雄技能伤害提升 250 → 300
  > ▼ 其主要天敌的关键装备被削弱
  > 来源：官方 18.3 版本更新公告 ↗

每条依据都可以点击查看官方公告原文。

### 2.2 局面咨询

输入你当前的局面，向助手提问。可填写的信息：

| 信息 | 示例 |
|---|---|
| 阶段 | 3-2 |
| 等级 | 7 |
| 金币 | 52 |
| 血量 | 41 |
| 连胜 / 连败 | W3 / L2 |
| 已有英雄 | 场上与备战席，含星级与装备 |
| 持有装备 | 按类型分类 |
| 海克斯 | 已选的与当前待选的三选一 |
| 对手信息 | 决赛圈针对用 |

也可以使用六个快捷指令，一键获得结论：

| 指令 | 回答什么 |
|---|---|
| **推荐方向** | 当前最优方向，以及本回合该做什么 |
| **海克斯选择** | 三选一，先给结论再给理由 |
| **D 牌决策** | 本回合该刷牌还是存钱 / 升人口，给具体金币预算 |
| **站位建议** | 当前阵容的最优站位 |
| **对手针对** | 根据对手信息给针对性思路 |
| **是否转型** | 该不该转型，转的话给目标和步骤 |

### 2.3 数据速查

搜索任何英雄、羁绊、装备或海克斯，查看完整数值。

这一层看起来像附属功能，但实际很重要：**你可以自己核实数据**，不必完全依赖助手的回答。

## 3. 怎么用

### 3.1 首次使用

1. 启动本地服务
2. 首次运行会自动同步当前赛季的游戏数据（约 23MB，需要一分钟左右）
3. 打开浏览器访问本地地址

同步完成后，数据会缓存在本地。之后再启动不需要重新下载，除非游戏更新了新版本。

### 3.2 日常查看阵容

打开后默认进入**阵容总览**。顶部状态条会显示：

```
● Set 18 · 补丁 18.3 · 同步于 3 小时前
```

点开任意阵容卡片的「为什么是 T0」，就能看到这套阵容在本补丁下的强弱依据。

### 3.3 对局中咨询

1. 切到**局面咨询**视图
2. 填写当前局面（填多少算多少，未填的字段会忽略）
3. 点击快捷指令，或直接输入问题
4. 回答会逐字流式显示，可以随时停止

**回答的固定结构是「结论 + 理由 + 依据」三段**，而不是一句话结论。

## 4. 几个重要的行为说明

### 4.1 关于数据版本

工具的可靠性取决于数据版本是否最新。因此在两处会明确提示：

| 情况 | 表现 |
|---|---|
| 数据与当前版本一致 | 状态条显示绿色，正常使用 |
| 数据落后一个补丁 | 状态条转为**警告色**，提示"结论可能已过时" |
| 数据赛季与预期不符 | **阻断并提示重新同步**，不提供服务 |

> 第三种情况会直接阻止使用，这是刻意的。云顶每约 4 个月更换赛季，会清空全部英雄与羁绊。如果换了赛季还在用旧数据，工具不会报错，只会持续输出上上个赛季的阵容——这比不能用更糟。

### 4.2 关于助手的回答可能有错

助手依赖语言模型组织回答，而语言模型**可能编造不存在的英雄或羁绊名称**。

因此工具做了两件事：

1. **回答中的名称会与真实数据比对。** 如果出现了数据中不存在的名称，会被**明确标红**并说明原因，而不是悄悄修正或隐藏。
2. **羁绊数量由程序重新计算。** 助手给出的阵容，其羁绊激活情况以程序计算结果为准。

> 看到标红的内容，说明那部分不可信。这也是一种信号：该回答的其他部分值得再核对一下。

### 4.3 关于哪些功能依赖语言模型

| 功能 | 需要语言模型 |
|---|---|
| 阵容总览 | ❌ 不需要 |
| 数据速查 | ❌ 不需要 |
| 局面咨询 | ✅ 需要 |

**未配置语言模型时，前两项功能完全可用。** 数据始终来自本地数据包，不经过模型。

## 5. 典型使用场景

### 场景一：新版本上线，看看环境变了什么

打开阵容总览，看梯队变化。点开升到 T0 的阵容，看它的依据是哪些改动生效了。

### 场景二：我擅长的阵容被削弱了吗

在阵容总览找到你的阵容，展开依据面板，看本次补丁是否削弱了它的核心英雄或核心装备。

### 场景三：开局不知道走什么方向

局面咨询 → 填写已有英雄、装备、海克斯 → 点「推荐方向」。

### 场景四：3-2 手上 50 块，纠结刷牌还是升人口

局面咨询 → 填写阶段、等级、金币、血量 → 点「D 牌决策」，会给出具体的金币预算建议。

### 场景五：决赛圈被针对

局面咨询 → 填写对手信息 → 点「对手针对」，给出针对性站位与克制思路。

### 场景六：不确定装备给谁

在数据速查里查该英雄的常用装备，或在局面咨询里直接问。

## 6. 当前不支持的

| 不支持 | 原因 |
|---|---|
| 自动识别游戏画面 | 需要训练视觉模型，非核心价值 |
| 真实胜率 / 登场率统计 | 第三方统计站无公开稳定接口 |
| 读取游戏内存 | 存在账号风险 |
| 账号系统与云端同步 | 定位是本地工具 |
